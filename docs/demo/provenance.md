# Data Provenance -- SIH26162 FireSense Demo

## Data Sources

| Source | Type | Resolution | Usage |
|--------|------|------------|-------|
| NASA FIRMS VIIRS 375m | Satellite thermal anomalies | 375m pixel | Primary hotspot detection (FRP, brightness temperature) |
| NASA FIRMS MODIS 1km | Satellite thermal anomalies | 1km pixel | Secondary/cross-validation sensor |
| OpenStreetMap Overpass API | Vector land-use boundaries | Building-level | Facility identification, landuse classification |
| ESA WorldCover 2021 | Land-cover classification | 10m/60m | Burn restriction zones, vegetation type |

## Curated vs Simulated Fields

Each scenario JSON file in `data/demo/` contains a `provenance` block documenting which fields are curated (derived from real satellite/OSM data) and which are simulated (for demo purposes).

### Curated Fields (based on real data patterns)
- `hotspots[].latitude`, `hotspots[].longitude` -- real coordinates
- `hotspots[].frp`, `hotspots[].brightness` -- realistic FRP/temperature values based on real event profiles
- `hotspots[].osm_context` -- real OSM land-use tags for the coordinates
- `historical_observations[]` -- simulated temporal patterns based on real event behavior

### Simulated Fields (demo-only, not from real-time data)
- `risk_score` -- computed composite danger score
- `risk_label` -- human-readable risk classification
- `assigned_authority` -- nearest emergency authority (distance/ETA are estimates)
- `assets_at_risk` -- nearby population centers, roads, hospitals
- `wind_corridor` -- simulated wind-driven smoke plume

## Alert Dispatch Labeling

All alert payloads generated by `backend/alerts.py` include:
- `"simulated": true`
- `"label": "SIMULATED DISPATCH -- Not connected to real emergency services"`

This label is mandatory and cannot be removed. The system explicitly does NOT claim to reach real emergency dispatch systems.

## Scenario Reproduction

Scenarios are deterministic:
- Same input coordinates produce identical classification results
- Historical observations are fixed in the JSON files
- Persistence scores are computed from the fixed observations
- No random or time-dependent components in demo mode

To verify: run `python data/seed.py` twice and confirm identical output.

## No Live NASA Calls in Demo Mode

When `DATA_SOURCE=cache` (default), the system uses pre-cached scenario data. No live NASA FIRMS API calls are made. Live mode requires a valid `FIRMS_MAP_KEY` environment variable and is opt-in via `?live_osm=1`.
